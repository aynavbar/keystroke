# Keystroke

Keystroke is my take on writing productivity tools. It works best for drafts where you just want a quick throw-away environment to work in. It helps you understand how you write by reacting to how you type and changing the ambiance as you go

## Key features
- The background subtly changes as a rolling gradient to react to typing intensity (Soft green for gentle typing, more yellow for faster typing and red for backspaces).
- Automatically copies the draft to keyboard when you end the session.
- Graph for spotting trends/correlations between WPM and inferred mood.
