# Keystroke

Keystroke is my take on productivity tools for writing. It's intended to be used for drafts. It helps you understand how you write by showing you important information like how fast you were typing during specific times in your session and how many times you erased content.

## Key Features

- The background subtly changes to react to typing intensity, and the change becomes aggressive as you remove content using the Backspace or Delete keys.
- It automatically copies the draft to your keyboard after you end a session
- Has a graph that shows you how fast you were typing. Higher is better and lower indicates slow flow of ideas
